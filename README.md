# PhysX

Десктопное обучающее приложение по физике. Название оставлено как рабочее и звучное.

## Стек

Проект переведен на .NET/WPF:

- C# - логика приложения и данные разделов.
- XAML/WPF - визуальная основа desktop-интерфейса.
- PNG-атлас - изображения для крупных кнопок разделов.

Почему так: WPF уже входит в Windows Desktop runtime, не требует скачивать UI-зависимости и хорошо подходит для первого нативного Windows-прототипа. Позже физические модели можно спокойно выносить в отдельные C#-модули, а тяжелые симуляции при необходимости подключать отдельными библиотеками.

## Запуск

После скачивания с GitHub самый спокойный запуск - через терминал из папки проекта:

```powershell
dotnet run
```

Проверочный запуск без открытия окна:

```powershell
dotnet run -- --smoke-test
```

Почему так: Windows может помечать `.cmd/.bat` из скачанного ZIP как файл из интернета и блокировать запуск. Это не ошибка приложения, а защитная метка Windows. Запуск через `dotnet run` не требует запускать скачанный скрипт.

Если хочется пользоваться батником локально:

```cmd
Run-PhysX.bat
```

Скрипт сначала публикует проект как single-file `PhysX.exe`, потом запускает готовое приложение.
В проекте также лежит локальный `NuGet.Config`, чтобы сборка не зависела от пользовательского NuGet-конфига Windows.
При первом запуске/публикации .NET может скачать runtime packs для `win-x64`.

После публикации можно запускать напрямую:

```cmd
bin\Release\net10.0-windows\win-x64\publish\PhysX.exe
```

## Сборка

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

## Если Windows блокирует батник

Лучший вариант - скачать репозиторий через Git:

```powershell
git clone https://github.com/Biolumeniscence/PhysX.git
cd PhysX
dotnet run
```

Если скачан ZIP с GitHub, можно перед распаковкой открыть свойства ZIP-файла и нажать `Разблокировать`, если такая кнопка есть. После этого распаковать заново. Это снимает метку "файл из интернета" со всех файлов внутри архива.

Сборочные папки `bin/`, `obj/` и `artifacts/` специально не лежат в GitHub. Они создаются автоматически при `dotnet run`, `dotnet build` или `dotnet publish`.

## Структура

- `PhysX.csproj` - проект WPF.
- `App.xaml` / `App.xaml.cs` - входная точка приложения.
- `MainWindow.xaml` / `MainWindow.xaml.cs` - главное окно, карточечная навигация и учебные разделы.
- `SettingsWindow.xaml` / `SettingsWindow.xaml.cs` - отдельное окно настроек.
- `Models/Topic.cs` - модель раздела.
- `Models/LearningOption.cs` - модель карточек внутри учебных разделов.
- `Models/LessonPage.cs` - модель страниц теоретического урока.
- `Run-PhysX.bat` - локальный запуск через single-file публикацию.
- `NuGet.Config` - источник NuGet для восстановления проекта.
- `assets/topic-atlas.png` - общий атлас изображений для кнопок.
- `assets/two-positive-particles.png` / `assets/two-negative-particles.png` - изображения для урока по электростатике.

## Текущая навигация

Главная страница открывает разделы физики. Раздел `Электричество` оставлен как каркас для будущих тем про ток, напряжение, сопротивление и цепи.

Раздел `Электростатика` уже имеет собственное карточечное меню: теория, задания с карточками, мини-лаборатория и справочник. Внутри `Электростатика -> Теория -> Электрический заряд` есть многостраничный теоретический урок с текстом, схемами, примерами и формулами.
